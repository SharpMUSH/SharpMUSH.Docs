# Sharpie marketing assets

`share-card.html` is the editable source for the 1280 × 640 social card. The mascot illustration is a distinct native-alpha generated asset; it is not reused from the README or Docs placements. Text is composed in HTML rather than baked into generation. The PNG export uses an opaque white background for predictable previews.

Palette authority: mint green `#00DDB3`, ink `#17333E`, white. Keep flat mascot fills, rounded white hind paws and complete silhouettes. Do not use palette normalization. The `.provenance.json` files record generation sources and export checks.

The generated share image is published at `/social/sharpie-docs.png`; Starlight's configured head supplies the absolute production URL, image dimensions and alternate text for Open Graph and Twitter. Per-page titles and descriptions remain Starlight's normal values. On-page Sharpie art is unchanged.

The original SharpMUSH M remains the primary brand identifier. `sharpmush-logo.svg` is an unchanged copy of the repository’s canonical logo used in the share-card source. Sharpie is a supporting mascot, not a replacement for the M.
