SharpMUSH can easily be installed locally, or on a remote server, thanks to Docker.
It is a MUSH server with a web portal attached, so installing it gets you both a telnet game and a
website for it.

To get started, pick the option that best aligns to your needs:

<LinkCard
  title="Try it first"
