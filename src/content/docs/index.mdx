## Get started with SharpMUSH

<CardGrid stagger>
	<Card title="Why SharpMUSH?" icon="magnifier">
		SharpMUSH is a modern iteration of the time tested MUSH frameworks, 
		retaining their softcode capabilities, offering C# Plugin Support.
		
		For more details, check out our article on our [Design Premise](/about/design-premise).
	</Card>

	<Card title="Bring over PennMUSH" icon="rocket">
		Use a tool to bring your PennMUSH data and configuration over! SharpMUSH is best-effort compatible.
		See our [Compatibility](/reference/compatibility/) and [Comparison](/reference/comparison/) Guides for details.
	</Card>
	<Card title="Runs on Docker" icon="seti:docker">
		Booting up a game is a single [Docker Compose command](/guides/docker-quickstart/).
		The same stack scales down to a €5/month VPS and up to Kubernetes.
	</Card>
	<Card title="See it running" icon="rocket">
		Our [live example game](https://mush.sharpmush.com) runs the current build.
		Create a character, or look around as a guest — no install required.
	</Card>
	<Card title="Configure your new MUSH" icon="setting">
		Configure, moderate and extend your game from the [web portal](/guides/web-portal/) —
		no config-file editing and no server restarts.
	</Card>
	<Card title="Extend it your way" icon="puzzle">
		Install [softcode packages](/guides/packages/) from a repository, or ship compiled
		[C# plugins](/guides/plugins/) without forking the engine.
	</Card>
	<Card title="Read the docs" icon="open-book">
		Learn more in our [SharpMUSH docs](/guides/get-started). 
		Looking for a specific command or function? Check out the [Helpfile Reference](/reference/sharpmush-help/sharptop/),
		generated from the server's own help topics.
	</Card>
</CardGrid>
