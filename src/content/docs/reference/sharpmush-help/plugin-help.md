## Plugin Help

A plugin can bring its own help, which is part of `help` for as long as the plugin runs. Each plugin running on this game that has help is listed below by name, with its topics. If nothing is listed, none of them has any.

Some plugin topics also appear on the lists they belong to, such as [@-wizard](/reference/sharpmush-help/sharpcmd/#wizard) or a category of the [function list](/reference/sharpmush-help/function-list/#function-list). See [@plugin](/reference/sharpmush-help/plugin-command/#plugin) for the plugins this game has.
