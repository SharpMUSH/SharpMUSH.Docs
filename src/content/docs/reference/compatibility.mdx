Planning to move a live game? Compatibility findings are inputs to a rehearsal, not proof that an
import is ready for players. Use the [migration runbook](/guides/pennmush-migration) to test your own
identities, data, softcode, connection paths, portal, and integrations.

SharpMUSH targets PennMUSH 1.8.8 softcode. Where it differs, the game's own help says how, one topic
per area. Each page below is the same text as that `help` topic in the game, and SharpMUSH's test
suite runs their examples against the server.

## TinyMUX and RhostMUSH

SharpMUSH also runs much of the softcode written for TinyMUX and RhostMUSH. A call PennMUSH refuses,
such as `switch(x,default)` or `ifelse(x,yes)`, is answered as those servers answer it. Where the
servers give the same code different answers, SharpMUSH keeps PennMUSH's unless a setting says
otherwise. [TinyMUX Softcode](/guides/tinymux-softcode) and
[RhostMUSH Softcode](/guides/rhostmush-softcode) cover each in full.
[Moving a RhostMUSH or TinyMUX Game](/guides/rhostmush-tinymux-import/) lists what an import brings
across and what it rewrites.

## What an import turns on

Importing a database turns on the settings its softcode expects, and the import report lists them.

| Imported from | Settings turned on |
|---|---|
| PennMUSH | `paren_groups`, `http_qregisters`, `mapsql_sync` |
| TinyMUX | `dialect` set to `mux`; `paren_groups`, `null_eq_zero`, `tiny_trim_fun`, `tiny_math`, `mux_logic`, `mux_justify`, `mux_collation`, `mux_arguments`, `mux_queue_functions`, `mux_quiet`, `mux_function_caller`, `innermost_tokens`, `rhost_list`, `protection_flags`, `attribute_eval_flags`; and `function_recursion_limit` set to 500 |
| RhostMUSH | `dialect` set to `rhost`; `paren_groups`, `tiny_trim_fun`, `mux_logic`, `rhost_edit`, `rhost_lattr`, `rhost_printf`, `rhost_map_args`, `rhost_list`, `rhost_lrooms`, `sidefx_flag`, `protection_flags`, `attribute_eval_flags`; and `mail` as a name for `@mail` |

The configuration file you give the import (`mush.cnf`, `netmux.conf` or `netrhost.conf`) is applied
too. The [Config](/reference/sharpmush-help/compatibility-config/) page says what each setting does.
