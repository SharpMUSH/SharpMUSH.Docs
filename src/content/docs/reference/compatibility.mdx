Planning to move a live game? Compatibility findings are inputs to a rehearsal, not proof that an
import is ready for players. Use the [PennMUSH migration runbook](/guides/pennmush-migration) to test
your own identities, data, softcode, connection paths, portal, and integrations.

SharpMUSH targets PennMUSH 1.8.8 softcode. Where it differs, the game's own help says how, one topic
per area. Each page below is the same text as that `help` topic in the game.

| Page | What it covers |
|---|---|
| [PennMUSH Compatibility](/reference/sharpmush-help/pennmush-compatibility/) | The overview: what kinds of difference there are, and where each is listed |
| [Parser](/reference/sharpmush-help/compatibility-parser/) | How a line is parsed, dispatched and evaluated: unbalanced brackets are an error, `##` in `iter()` is data, a function name can't be produced by evaluation |
| [Arguments](/reference/sharpmush-help/compatibility-arguments/) | Functions that take extra, optional arguments |
| [Names](/reference/sharpmush-help/compatibility-names/) | Functions and commands that PennMUSH doesn't have, or that take their arguments in another order |
| [Commands](/reference/sharpmush-help/compatibility-commands/) | The command table, the configuration and the objects a new game starts with |
| [Config](/reference/sharpmush-help/compatibility-config/) | Configuration options that change how existing code evaluates, such as `tiny_booleans` and `tiny_math` |
| [Output](/reference/sharpmush-help/compatibility-output/) | `render()` and markup written for something outside the game |
| [Identity](/reference/sharpmush-help/compatibility-identity/) | Object identity, timestamps and numbers |
| [Mail](/reference/sharpmush-help/compatibility-mail/) | The differences in `@mail` |
| [Economy](/reference/sharpmush-help/compatibility-economy/) | Currency and `money()` |
| [Defects](/reference/sharpmush-help/compatibility-defects/) | Differences that are bugs, expected to change |
| [Unresolved](/reference/sharpmush-help/compatibility-unresolved/) | Differences with no decision yet; don't depend on either behaviour |

Code written for TinyMUX or RhostMUSH has guides of its own:
[TinyMUX Softcode](/guides/tinymux-softcode) and [RhostMUSH Softcode](/guides/rhostmush-softcode).
