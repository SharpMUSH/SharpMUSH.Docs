# Sharpie documentation illustrations

These illustrations support three entry points, rather than decorating generated reference pages:

| Asset | Placement | Purpose |
| --- | --- | --- |
| `sharpie-world-builder.webp` | Homepage Starlight hero | Introduce Sharpie building a world beside the existing documentation and demo actions. |
| `sharpie-first-steps.webp` | Get Started, after the introduction | Welcome new builders before they choose an installation route. |
| `sharpie-packages.webp` | Softcode Packages, after the introduction | Illustrate reusable building blocks before the plan/review/apply explanation. |

The header retains the canonical SharpMUSH M logo. These are editorial mascot illustrations, not replacements for the approved logo masters.

## Rendering rules

- Keep headings, instructions and links in HTML; the images contain no required information.
- Use empty alternative text for these decorative placements. The guide component also hides its wrapper from assistive technology.
- Preserve native alpha. These were generated with transparent backgrounds, not extracted or matted from opaque art.
- Do not add background panels, crop with `object-fit: cover`, recolor white fur for dark mode, or apply CSS color filters.
- Keep guide art compact and responsive; load it lazily and reserve its aspect ratio. The homepage hero loads eagerly through Starlight.
- Review on white and dark page backgrounds, including mobile. Keep ears, paws and scenery inside the image bounds.

## Provenance

Generated with the built-in OpenAI image generation tool using the approved Sharpie identity preview as a reference. `provenance.json` records source PNG hashes and export details. Each WebP was encoded losslessly and checked for exact RGBA equality with its generated PNG. The opaque drafts and abandoned atlas background-removal experiments are not used here.

The generation briefs requested ink/mint/pure-white, a readable forehead M and rounded muzzle, full silhouettes, no text, and native transparency. The scenes were a small constructed world, a path to an open doorway, and a package of reusable blocks respectively.
